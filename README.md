# krathveil.com coming soon

The pre-launch site for **Krath Veil Defence Systems** (Hyderabad, India).

> Dominate. Connect. Disappear.

A single-page, dependency-free site (no build step, no external fonts) deployed via
GitHub Pages on the `krathveil.com` apex domain (see `CNAME`).

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The coming-soon page. Self-contained, inline CSS + JS. |
| `samarth.html` | Founder profile / contact card (linked from the footer). |
| `krathveil-mark.png` | Transparent wordmark, shown on the OLED hero panel. |
| `krathveil.svg` | High-resolution vector wordmark (gold on black). |
| `logo.jpg` | Open Graph / social-share image. |
| `CNAME`, `.nojekyll` | GitHub Pages config. |

## Design

Built to the Krath Veil house style: Georgia throughout, gold (`#C9B06B`) as the only
accent, sharp 90° corners, classification framing, and a declarative, restrained voice.
The dark "OLED" treatment echoes the field node's display.

## Deploy

Commit to `main`; GitHub Pages publishes automatically.
